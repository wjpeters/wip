# M0 · beslis- en ontwerpbewijs

Datum 2026-09-24. Invoer: het volledige zesdocumenten-developerpakket in Downloads/modern-trade-terminal 2. Het eerdere project in Downloads/modern-trade-terminal is gelezen en behouden. Bruikbare basis en vier ontwerpbeelden zijn naar een nieuwe lokale werkmap gekopieerd; financiële, auth- en UI-kern zijn opnieuw uitgewerkt. Oude tests zijn uitsluitend archief, geen huidig bewijs.

Host: Apple arm64, macOS 26.6.2, 16 GB RAM. Docker Desktop 4.38; Engine 27.5.1; Compose 2.32.4. Docker VM: 10 CPU's en 8.22 GB beschikbaar. Werkelijke resources in Compose begrensd. Node 25.2.1, npm 11.12.1, Python 3.13, Cargo 1.91.1. Dit is een compact profiel, niet de voorgestelde 32-GB referentiemachine voor M5.

- [ADR 0002](../adr/0002-local-m1.md): architectuur, alternatieven en consequenties.
- [Schema](../../packages/contracts/schema.json): Identity, Quote, Trade, OrderIntent, JournalLine, TaxRule, versievelden en decimal strings.
- [Generatiebewijs](contract-drift.txt), [Rust-compile](contracts-rust.txt), [backendtests](tests-api.txt).
- [Bron- en licentiematrix](../providers/entitlements.md): publieke docs versus operationele toegang.
- [Visueel contract](../design/IMPLEMENTATION_CONTRACT.md) en vier [referentiebeelden](../design/README.md), voorafgaand aan brede UI-implementatie.
- [Fixturemanifest](../../fixtures/README.md): synthetische gegevens, geen providerbewijs.

Geen live orderrechten, abonnementen of modelcalls geactiveerd. Het WPOS-indexbestand verwijst naar de lokale map; geen broncode of secrets onder iCloud geplaatst. Baselineimages zijn op digest vastgelegd in Dockerfiles/Compose en [images.lock](../../infra/images.lock).
